# Agent notes (brigadebotsdk)

This checkout holds no SDK source: the repo root contains only a GPLv3 `LICENSE` file. There is no README, no `docs/` folder, no build file, and no CI configuration.

Bot API knowledge actually lives in the sibling brigade repo: [`../brigade/docs/ai-notes.md`](../brigade/docs/ai-notes.md) documents the call sequence for a bot hosting or joining a game.
